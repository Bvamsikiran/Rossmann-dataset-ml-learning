# Rossmann Machine Learning Lab

## Project Guidelines
- **Architecture**: Decoupled fullstack system featuring a React/Vite/TanStack frontend and a Python (FastAPI + Pandas + Scikit-Learn) backend in `backend/`.
- **Dataset Integration**: Seamless relational joining across the Rossmann dataset family (Train, Store, Store States, Weather, Google Trends).
- **Frontend**: Responsive, modern analytics interface comparing Linear Regression with K-Nearest Neighbors (KNN).
